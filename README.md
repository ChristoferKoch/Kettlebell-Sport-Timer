# Kettlebell Sport Timer
A timer to track kettlebell workouts.

### Introduction
This is meant to be more than just a simple timer. The idea is to create custom workouts with intervals, pacing, and weight data. That is its most basic (free) function.

Beyond this, it will have predetermined workout plans, an intensity selector based on past data, workout analytics, and a neural network to create workout plans or predict when or how likely within a certain day you are to peaking.
